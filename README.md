# Interactive Calendar — Frontend Intern Task

## Overview

This is a responsive interactive calendar built using React, TypeScript, Tailwind CSS, and Framer Motion.

The component supports:

* Month navigation
* Date range selection
* Notes for each month
* Dark mode toggle
* Responsive mobile & desktop layout
* Animated page transitions
* Hanging calendar UI

---

## Tech Stack

* React
* TypeScript
* Tailwind CSS
* Framer Motion
* Lucide Icons
* Vite

---

## Features

### Interactive Calendar

* Navigate between months
* Select date ranges

### Notes Feature

* Add notes per month
* Stored in localStorage

### Animations

* Page flip animation
* Hanging calendar animation

### Responsive Design

* Mobile friendly
* Desktop optimized

---

## How to Run Locally

Clone the repository:

```bash
git clone <your-repo-link>
```

Go to project folder:

```bash
cd interactive-calendar
```

Install dependencies:

```bash
npm install
```

Run project:

```bash
npm run dev
```
